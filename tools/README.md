# Диагностика скорости VPN на VPS

`diagnose-vpn.py` собирает счётчики Linux за 30 секунд: реальную загрузку CPU
по приращениям `/proc/stat`, CPU steal/iowait, память, скорость и ошибки
сетевых интерфейсов, ошибки UDP, MTU и сведения об очередях `tc`.
Сведения WireGuard сводятся к количеству пиров, возрасту последнего handshake
и суммарному трафику.

Скрипт работает на Python 3.8+ со стандартной библиотекой. Он читает системные
счётчики, выполняет команды `wg show` и `tc show`, выводит JSON в консоль.
Сетевых запросов, установки пакетов, перезапуска VPN и записи настроек нет.
Отчёт исключает IP-адреса, ключи пиров, содержимое конфигураций и токены.
Если `wg`/`tc` недоступны, соответствующий раздел явно помечается как недоступный.

## Запуск

В консоли **самого VPN-сервера**, из каталога репозитория:

```bash
sudo python3 tools/diagnose-vpn.py --seconds 30
```

После появления `Sampling host counters` сразу начните тест скорости на
телефоне с подключённой Eneida. Скопируйте итоговый JSON из консоли.
Для записи отчёта в файл можно добавить `> eneida-diagnostics.json`.
На сервере с WireGuard в контейнере счётчики WireGuard нужно собирать в его
сетевом пространстве имён: пустой список интерфейсов на хосте ничего не говорит
о состоянии туннеля внутри контейнера.

## Как читать

- `cpu.aggregate.active_pct` и `cpu.busiest_core_active_pct`: загрузка за интервал;
  CPU steal показывает время, когда виртуальный CPU не получал процессор хоста.
- `links.*.delta`: приращения счётчиков за интервал. `null` обозначает отсутствие
  данных или сброс счётчика, а не нулевое количество ошибок.
- `rx_mbps`/`tx_mbps`: средняя скорость **со стороны сервера**, а не предельная
  пропускная способность. Значения осмысленны при одновременном замере на телефоне.
- `protocol_counter_delta`: счётчики всего сетевого пространства имён.
  Например, рост `UdpRcvbufErrors` указывает на потери при переполнении буфера
  UDP; это не измерение потерь на всём пути от телефона до сервера.
- `qdiscs`/`traffic_classes`: текущие параметры очередей и накопленные счётчики.
  Их значения могли накопиться задолго до запуска диагностики.
- `wireguard`: доступность интерфейсов и свежесть handshake; успешный handshake
  сам по себе не измеряет скорость или отсутствие утечек.

Отчёт помогает выбрать следующую проверку. Он не определяет автоматически
доступную скорость VPS, PMTU маршрута или ограничения UDP у мобильного оператора.

Источники формата счётчиков:
[Linux /proc](https://docs.kernel.org/filesystems/proc.html),
[Linux SNMP counters](https://docs.kernel.org/networking/snmp_counter.html),
[WireGuard wg(8)](https://git.zx2c4.com/wireguard-tools/about/src/man/wg.8).
