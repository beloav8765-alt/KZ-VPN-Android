# Eneida: визуальный стиль 0.9.3

В основе знака — щит и буква E, вырезанная тремя направленными линиями.
Один вектор используется в заголовке, иконке приложения и монохромной
иконке Android 13+. Знак сохраняет прозрачность внутри буквы.

| Назначение | Цвет |
| --- | --- |
| Фон | `#0C1118` |
| Карточка | `#151D28` |
| Поднятая поверхность | `#1C2734` |
| Основной акцент | `#78E4CB` |
| Основной текст | `#F4F8FB` |
| Вторичный текст | `#A2B2C5` |

- [Знак SVG](eneida-mark.svg) — прозрачный фон, масштабируемый исходник.
- [Иконка SVG](eneida-icon.svg) — вариант на тёмном скруглённом фоне.
- Главное действие остаётся в центре экрана. Сервер, трафик и настройки
  собраны в отдельные карточки с согласованными отступами и иконками.
- Статусы отражают состояние туннеля; дизайн не добавляет обещаний о проверке
  утечек или измеренной скорости, которых приложение не выполняет.
- Общая палитра применяется к главному экрану, серверам, регионам и подписке.
  Контент учитывает системные панели и вырезы экрана Android 16.

## Предварительная сборка

```bash
gradle :app:assemblePreview
```

APK `app/build/outputs/apk/preview/app-preview.apk` устанавливается как
**Eneida Preview**, с отдельным application ID `com.kzvpn.app.v032.preview`.
Для подключения в этой установке требуется добавить профиль сервера.

Workflow `Eneida design preview` собирает APK, запускает его в Android 16
и сохраняет реальные снимки главного экрана, списка серверов и крупного текста.
На снимках показана новая установка с отключённым VPN.


## Кнопка и эффекты 0.9.4

Нативный `EneidaPowerButton` повторяет утверждённые состояния: светлая мятная
кнопка «Включить» и тёмная бирюзовая «Выключить» со светящимся контуром.
Градиенты и символ питания рисуются Canvas, текст остаётся доступным TalkBack.
При касании есть мягкое нажатие, волна и системный тактильный отклик; смена
состояния плавно меняет заливку. Во время подключения движется дуга, после
подключения проходит один затухающий импульс. В фоне эффекты остановлены;
системное отключение анимаций учитывается.

Сборка `effects` (`gradle :app:assembleEffects`) устанавливается как **Eneida FX**,
с application ID `com.kzvpn.app.v032.fx`. Нажатие на бейдж FX открывает отдельно
подписанную демонстрацию двух состояний. Она не управляет VPN; главный экран
по-прежнему использует реальное состояние `VpnController`.

Workflow сохраняет PNG состояний и MP4 переходов с Android 16. APK, выдаваемый
пользователю, подписывается постоянным ключом FX после сборки; закрытый ключ
хранится отдельно от репозитория. Сырой CI APK использует временную debug-подпись.
