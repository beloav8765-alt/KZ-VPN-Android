# KZ VPN Android

Личный Android-клиент WireGuard.

## Версия 0.3.1

- импорт стандартного WireGuard `.conf`;
- подключение и отключение одной кнопкой;
- статистика входящего и исходящего трафика;
- Always-on VPN / Kill Switch через системные настройки Android;
- конфигурация хранится локально в зашифрованном виде через Android Keystore;
- улучшенная диагностика ошибок импорта конфигурации.

Репозиторий не содержит приватных VPN-ключей, паролей или серверных конфигураций.

## APK

GitHub Actions автоматически собирает debug APK и публикует его как artifact `KzVpn-0.3.1-debug`.
