# Eneida VPN (Android)

Android-клиент WireGuard. Актуальная версия в `app/build.gradle.kts`: **0.9.4**.
До выпуска исправлений используйте стабильную сборку своей установленной версии.

## Возможности

- Подключение и отключение WireGuard одной кнопкой, статистика трафика и скорость передачи.
- Ручной импорт нескольких стандартных WireGuard `.conf` и выбор сервера.
- Управляемый режим Eneida: подписка, автоматическая выдача профиля и выбор региона
  при наличии HTTPS Control API (`ENEIDA_API_BASE_URL` при сборке).
- Зашифрованное локальное хранение конфигураций с Android Keystore.
- Поддержка системных функций Android **Always-on VPN** и
  **«Блокировать подключения без VPN»** через настройки VPN на устройстве.

**Безопасность:** наличие активного туннеля само по себе не подтверждает
отсутствие DNS- и IPv6-утечек. Для блокировки трафика при сбое VPN включите
системную опцию Android «Блокировать подключения без VPN» и проверьте её
поведение на устройстве. Не публикуйте приватные ключи или серверные профили.

## Сборка и тесты

Требуются Java 17, Android SDK 36 и Gradle 8.13.

```bash
gradle :app:testDebugUnitTest :app:assembleDebug
```

GitHub Actions выполняет тесты и debug-сборку для pull requests в `main`.
При успешной сборке публикуется artifact **Eneida-0.9.4-debug**. APK внутри
артефакта предназначен для тестирования, а не для подписанного релиза.

## Ручная проверка перед выпуском

1. Импорт нормального `.conf` и отказ в импорте файла более 1 МиБ.
2. Подключение, отключение, быстрое повторное нажатие и переключение сервера.
3. Смена Wi-Fi / мобильного интернета и восстановление работы VPN.
4. Автонастройка: отказ нового сервера не должен удалять рабочий профиль.
5. Трафик DNS и IPv6, Always-on VPN и «Блокировать подключения без VPN».

Репозиторий не содержит приватных VPN-ключей, паролей или серверных конфигураций.

## Диагностика скорости на VPS

Для замедления, подтверждённого сравнением с подключением без VPN, доступен
[сборщик системных счётчиков](tools/README.md). Запускайте его на VPN-сервере
одновременно с тестом скорости на телефоне, чтобы проверить CPU, ошибки UDP,
сетевые интерфейсы и очереди.
